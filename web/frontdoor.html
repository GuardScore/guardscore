How it works

One score. A growing set of engines.

Guard Score is a Lighthouse-style score for backend security — one number, and a purpose-built engine under the hood for each stack. This page gives an instant static read; the full engine builds a private copy of your backend and attacks it to prove every hole. Supabase is live and blind-benchmarked; Firebase and more are rolling out.

01

Paste your schema

Your create table and create policy statements. It never leaves the page — the check runs in your browser.

02

Read your Guard Score

A 0–100 score and every obvious hole in plain English: anyone-can-read, anyone-can-write, public buckets — with the fix.

03

Prove it with the verifier

One command builds a private Postgres copy and attacks it as a real intruder, confirming each hole and that your own users still work.
