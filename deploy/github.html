Guard Score

Add Guard Score to your repo — no terminal

Guard Score runs inside your own GitHub Actions. On every change it builds a private copy of your backend, attacks it as a stranger and as another logged-in user, proves any leak, and posts a 0–100 score right on your pull request. You never open a terminal, and your code never leaves your infrastructure.

What happens when you click

  1. The workflow is copied to your clipboard and GitHub opens a new-file editor in your repo, pre-set to .github/workflows/guardscore.yml.
  2. Paste (⌘V / Ctrl-V) into the editor, then click Commit changes. No terminal, no local setup.
  3. Done. GitHub runs Guard Score on every push and pull request from now on, and posts the score with proof. Add the badge to your README to show it off.
Where does the attack run? Entirely inside your own GitHub Actions runner — GitHub's ephemeral CI, in your repo's context. Your source, schema, and secrets are never sent to Guard Score's servers. It's the same engine as the CLI, just triggered by GitHub instead of your keyboard.

Prefer to do it by hand?

Create a file named .github/workflows/guardscore.yml in your repo and paste this in:

.github/workflows/guardscore.yml
